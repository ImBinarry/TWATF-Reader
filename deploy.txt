Cloudflare now steers new projects to Workers, which is why you got `workers.dev`. A `pages.dev` address only comes from a Pages project, and Pages still works for new projects through the command line. Your repo's deploy workflow already runs `wrangler pages deploy`, so you only need to create a Pages project named `twatf` and point the workflow at it.

**1. Log in to Cloudflare from the terminal:**

```bash
cd ~/IdeaProjects/TWATF-Reader/website
npx wrangler login
```

A browser tab opens. Approve the login.

**2. Create the Pages project:**

```bash
npx wrangler pages project create twatf --production-branch main
```

The site will live at `https://twatf.pages.dev`. Pages names are shared across all of Cloudflare, so if `twatf` is already taken the command will fail or give you a different name. In that case pick another (for example `twatf-reader`) and use it everywhere below.

**3. Set the project name in the workflow, and your real URL in the other files:**

```bash
cd ~/IdeaProjects/TWATF-Reader
sed -i 's/--project-name=YOUR-CLOUDFLARE-PROJECT/--project-name=twatf/' .github/workflows/deploy-website.yml
grep -rl "YOUR-PROJECT.pages.dev" --exclude-dir=node_modules --exclude-dir=.git . | xargs sed -i 's#YOUR-PROJECT.pages.dev#twatf.pages.dev#g'
grep -rn "project-name\|twatf.pages.dev" .github giscus.json website/src/lib/site.ts
```

The last command should show your project name in the workflow and `twatf.pages.dev` in the other files.

**4. Give GitHub permission to deploy.** You need two values:

- **Account ID:** in the Cloudflare dashboard, open **Workers & Pages**. The Account ID is in the right-hand sidebar.
- **API token:** go to **My Profile → API Tokens → Create Token → Create Custom Token**. Under Permissions choose **Account → Cloudflare Pages → Edit**, then create it and copy the token. You only see it once.

Then, in your GitHub repo, open **Settings → Secrets and variables → Actions → New repository secret** and add two secrets with these exact names:

```
CLOUDFLARE_ACCOUNT_ID
CLOUDFLARE_API_TOKEN
```

**5. Push and run the deploy:**

```bash
git add -A
git commit -m "Deploy to Cloudflare Pages"
git push
```

On GitHub, open the **Actions** tab, choose **Build & Deploy Website**, and click **Run workflow**. When it finishes, `https://twatf.pages.dev` should load. This workflow only runs when you start it by hand or on the 1st and 15th of each month, so you have to run it again after every change you want published. If you'd like it to deploy on every push to `main`, tell me and I'll give you the two-line change.

**6. Remove the old Workers site.** Once the new one works, open **Workers & Pages**, click the `twatf` Worker, go to **Settings**, and delete it. Otherwise it stays online and keeps rebuilding from your repo.
